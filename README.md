# Pokédex Evolution Tool

A Python tool that fetches live Pokémon evolution data from PokéAPI.

## Features

- Look up any Pokémon by name
- Shows full evolution chain with levels
- Handles special evolutions (happiness, stone, trade)
- Live data from pokeapi.co

## How to run

bash
pip install requests
python3 pokedex.py

## Example

Enter a Pokémon name: charmander

🔥 Charmander Evolution Chain:
Charmander → evolves at level 16
Charmeleon → evolves at level 36
Charizard → final form
